Orientation of the Home Assistant dashboard only, the other screens of the weather station stay landscape. The display is rotated while the dashboard is shown and switched back when it is left. Without the rotation lock the dashboard follows the MPU-6050 of the sensor plugin (0/90/180/270 degrees, aligned with the rotation offset of the sensor), this setting is the orientation it starts with after a reboot. The grid of /hass.yaml is written for the landscape layout and transposed for portrait (4x3 becomes 3x4), so the file does not have to change with the orientation. The tiles keep the order of the file in both orientations (left to right, top to down)
