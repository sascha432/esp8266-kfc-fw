# JC3248W535 (Shenzhen Jingcai Intelligent)

3.5" ESP32-S3 IPS touch display module. Datasheet in this folder:
`JC3248W535 Specifications-EN.pdf` (SKU `JC3248W535C_I_Y`).

## Specs

| Item | Value |
|---|---|
| Module | ESP32-S3-WROOM-1, dual-core @ 240 MHz, 512 KB SRAM, 384 KB ROM |
| Flash / PSRAM | 16 MB flash / 8 MB PSRAM (datasheet) |
| Radio | Wi-Fi + Bluetooth (integrated in the module) |
| USB | USB-C (one-click download; no separate UART bridge needed) |
| Panel | 3.5" TFT, IPS, 320x480, 16-bit RGB (65K colors) |
| Effective display area | 73.4 x 49.0 mm |
| Module size | 94.5 x 62.0 mm |
| Operating voltage / current | 5 V / ~150 mA |
| Temperature range | -20 .. +70 degC (storage -30 .. +80 degC) |
| Touch | capacitive, integrated in the display controller |
| Camera | none |
| Audio | none documented |
| Storage | TF (microSD) card slot reserved on the module |
| Free IO | up to 12 IOs usable by the application |
| Extras | Li-battery charge/discharge circuit with protection |
| PlatformIO env | `jc3248w535_debug` (`board = esp32-s3-devkitc-1`) |
| Debug probe | on-board USB-Serial/JTAG (`debug_tool = esp-builtin`) |

## Display

| Item | Value |
|---|---|
| Driver chip | AXS15231B (datasheet) |
| Bus | QSPI, 40 MHz |
| Resolution / color | 320x480, RGB565 |

| Signal | GPIO | Note |
|---|---|---|
| CS | 45 | |
| CLK (SCK) | 47 | |
| D0 | 21 | |
| D1 | 48 | |
| D2 | 40 | |
| D3 | 39 | |
| Backlight | 1 | |
| RST | - | not connected (drivers pass "undefined") |
| DC | - | not used, QSPI command framing |

The datasheet's interface diagram is an image, so the pin table comes from three
independent implementations: ESPHome `mipi_spi` model `JC3248W535`, Arduino_GFX
`Arduino_AXS15231B` / `Arduino_ESP32QSPI(45, 47, 21, 48, 40, 39)`, and the
`me-processware/JC3248W535-Driver` / `straga/micropython_lcd` ports.

## Touch

| Item | Value |
|---|---|
| Controller | AXS15231B (same chip as the display controller) |
| Bus / address | I2C, 0x3B |
| SDA | 4 |
| SCL | 8 |
| INT | 3 |
| RST | not documented |

Ignore the sources that claim touch SDA 15 / SCL 16 / INT 41 - that contradicts the
reference implementations above.

## Camera

Not supported - no camera connector or sensor.

## Audio

Not documented - no codec/DAC/amplifier listed in the datasheet.

## Storage / other

- TF card (microSD) slot reserved on the module.
- Up to 12 free IOs.
- Li-battery charging circuit.

## Build notes

- PlatformIO: `board = esp32-s3-devkitc-1` with 16 MB flash + 8 MB PSRAM, see
  `sdkconfig.jc3248w535` (OPI/octal PSRAM).
- GUI: LVGL via `lib_deps` (env uses LVGL 9.x; switch to `${lvgl8...}` for 8.x).
  A full-screen canvas/framebuffer is required because the panel has no RAM of its own.
- Display/touch driver stack: AXS15231B QSPI panel driver + AXS15231B I2C touch driver.
- ESPHome equivalent that is known to work: `display: platform: mipi_spi, model: JC3248W535`.
