# JC4880P443C-I-W (Shenzhen Jingcai Intelligent)

4.3" ESP32-P4 + ESP32-C6 MIPI-DSI touch display module.
Datasheet in this folder: `JC4880P443C_I_W Specifications-EN-V1.0.pdf`.
Vendor reference repository: https://github.com/wegi1/ESP32P4-JC4880P443C-I-W

## Specs

| Item | Value |
|---|---|
| Module | ESP32-P4, dual-core RISC-V, main frequency up to 360 MHz (datasheet) |
| Internal memory | 768 KB HP L2MEM, 32 KB LP SRAM, 128 KB HP ROM |
| Flash / PSRAM | 16 MB flash / 32 MB PSRAM (datasheet) |
| Radio | datasheet says "integrated Wi-Fi and Bluetooth" - the ESP32-P4 itself has **no radio**, so Wi-Fi/BT comes from the on-board **ESP32-C6** module |
| USB | several USB-C ports; flash via the port labelled "USB2" (USB Serial/JTAG) |
| Panel | 4.3" TFT, IPS, 480x800, 16.7M colors (24 bit) |
| Effective display area | 93.60 x 56.16 mm |
| Module size | 117.01 x 69.41 mm |
| Operating voltage / current | 5 V / ~320 mA |
| Temperature range | -20 .. +70 degC (storage -30 .. +80 degC) |
| Touch | capacitive (GT911), "without touch" variant also exists |
| Camera | MIPI-CSI, OV02C10 sensor is the one the vendor ships docs for |
| Audio | ES8311 codec + amplifier, microphone input, speaker output |
| Storage | TF (microSD) card slot, 4-bit SDMMC |
| Extras | RS485 transceiver, lithium battery interface circuit |
| SKU | `JC4880P443C_I_W` (no shell) / `JC4880P443C_I_W_Y` (with shell) |
| PlatformIO envs | `jc4880p443c_lvgl8_debug`, `jc4880p443c_lvgl9_debug` |
| Debug probe | on-board USB-Serial/JTAG (`debug_tool = esp-builtin`) |

## Camera

MIPI-CSI interface. The vendor repository ships the **OV02C10** (2 MP) sensor datasheet, so
that is the intended camera. The CSI data lanes and SCCB pins are not documented in the spec
PDF - check `5-Schematic/2_LCD&CSI.png` in the vendor repo. The reference implementation used
by the vendor demos wires the CSI SCCB to SCL 8 / SDA 7 (shared with the touch bus).

## Storage / other

- microSD via SDMMC 4-bit: D0 39, D1 40, D2 41, D3 42, CMD 44, CLK 43.
- RS485 transceiver on board (see `5-Schematic/5_485.png`); GPIOs not documented in the spec PDF.
- Buttons / LEDs not documented in the spec PDF (see `5-Schematic/7_OTHER.png`).

## LVGL

| Item | LVGL 8.x | LVGL 9.x |
|---|---|---|
| Component | `lvgl/lvgl@^8.4.0` | `lvgl/lvgl@^9.6.0` |
| PlatformIO env | `jc4880p443c_lvgl8_debug` | `jc4880p443c_lvgl9_debug` |
| Vendor demo | `1-Demo/arduino_examples/lvgl_demo_v8` | `1-Demo/arduino_examples/lvgl_v9_sw_rotation` |
| API | `lv_disp_drv_t` / `lv_indev_drv_t` | `lv_display_t` / `lv_indev_t` |
| Notes | classic API, lots of existing display code | newer API; the vendor P4 demo rotates in software on this panel |

- The LVGL port/glue component is `espressif/esp_lvgl_port`: v1.x targets LVGL 8,
  v2.x targets LVGL 9 - confirm the version when adding it as an IDF component.
- Driver stack for either version: `esp_lcd` MIPI-DSI DPI panel (ST7701S) + `esp_lcd_touch` GT911
  + the LVGL port, with a draw buffer in the 32 MB PSRAM.

## Build notes

- ESP-IDF target `esp32p4`. The vendor Arduino demos were built with **arduino-esp32 v3.2.1**.
- PlatformIO: no ESP32-P4 board in the official platform, so these envs use the pioarduino fork
  (`board = esp32-p4-evboard`) or a custom board definition.
- PSRAM: the datasheet lists 32 MB; enable `CONFIG_SPIRAM` in `sdkconfig.jc4880p443c` after
  confirming the mode on real hardware (`pio run -t menuconfig -e jc4880p443c_lvgl9_debug`).
