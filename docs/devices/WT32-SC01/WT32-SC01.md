# WT32-SC01 (Wireless-Tag)

3.5" ESP32 touch display board. Datasheet in this folder: `WT32-SC01-datasheet.pdf`.

Note: the vendor PDF describes a WROVER-B module with 8 MB PSRAM ("8Mbyte PSRAM + 4Mbyte Flash");
the unit used in this project has **4 MB PSRAM** - do not "correct" it back to 8 MB.

## Specs

| Item | Value |
|---|---|
| Module | ESP32-WROVER-B (Xtensa LX6 dual-core @ 240 MHz) |
| Flash / PSRAM | **4 MB SPI flash / 4 MB PSRAM** (own unit) |
| Radio | Wi-Fi + Bluetooth Classic / BLE |
| USB | Micro-USB via CP2104 USB-UART bridge (no native USB) |
| Panel | 3.5" LCM, 320xRGBx480, screen model WT-352215-A2 |
| Display interface | SPI, wired to the ESP32 HSPI (SPI2) peripheral |
| Touch | Capacitive, separate I2C controller (6-pin, 0.5 mm FPC) |
| Camera | none |
| Audio | none |
| PlatformIO env | `wt32_sc01_debug` (`board = esp32dev`) |
| Debug probe | no USB-JTAG in the ESP32 -> external probe (`debug_tool = esp-prog`) |

## Touch

| Item | Value |
|---|---|
| Controller | FT6236 / FT6336U |
| Bus / address | I2C, 0x38, 400 kHz |
| SDA | 18 |
| SCL | 19 |
| INT | not wired / not documented (polled) |
| RST | not documented |

## Camera

Not supported - the board has no camera connector.

## Audio

Not supported - no codec, DAC or amplifier on the board.

## Storage / other

- No microSD slot, no RS485, no battery charger.
- 2x 2.0 mm 2x20 pin headers with the remaining GPIOs.
- The self-reset button is connected to the ESP32 `EN` pin.

## Build notes

- PlatformIO: `board = esp32dev`; PSRAM (4 MB, quad SPI) must be enabled in the SDK config -
  see `sdkconfig.wt32_sc01`.
- GUI: LVGL via `lib_deps` (the env uses LVGL 9.x; switch the `lib_deps`/`build_flags`
  interpolation to `${lvgl8...}` for LVGL 8.x).
- Display/touch driver stack: `esp_lcd` SPI panel (ST7796) + FT6x36 I2C touch driver.

## WT32-SC01-PLUS (different board, ESP32-S3)

Do not mix these two up - the PLUS variant uses an 8-bit i80 parallel bus, not SPI:

| Item | Value |
|---|---|
| Module | ESP32-S3 (`WT32-S3-WROVER-N16R2`), 16 MB flash / 2 MB PSRAM |
| USB | USB-C with native USB-Serial/JTAG |
| Display | ST7796UI, i80 8-bit: DB0-DB7 = 9, 46, 3, 8, 18, 17, 16, 15; WR 47; RS 0; TE 48; RST 4; BL 45 |
| Touch | FT6336U, SDA 6 / SCL 5 / INT 7 / RST 4 |
| Audio | NS4168 class-D amp, I2S LRCK 35 / BCLK 36 / DOUT 37 |
| Storage | microSD SPI CLK 39 / MISO 38 / MOSI 40 / CS 41; RS485 TXD 42 / RXD 1 / RTS 2 |

Source: `arduino-esp32/variants/wt32-sc01-plus/pins_arduino.h` (official variant).
