The libraries required by this project:

    https://github.com/sascha432/KFCLibrary.git
    https://github.com/sascha432/ESPAsyncWebServer.git

A URL can be cloned in this directory or declared in "lib_deps" in
conf/common.ini (pulled in by platformio.ini "extra_configs"):

lib_deps =
    https://github.com/sascha432/KFCLibrary.git
    https://github.com/sascha432/ESPAsyncWebServer.git

"lib_deps" wins: a URL declared there is downloaded into .pio/libdeps/<env>
once per environment and that downloaded copy is compiled. A copy in this
directory is used only while the URL is not declared in "lib_deps" - clone it
in here and comment the declaration out to build from it.
